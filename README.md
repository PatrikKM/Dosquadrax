# Dosquadrax # QUADRAX: Chrám zapomenutých bohů (HTML5 Remake)

Plně offline HTML5 / Canvas pocta legendární slovenské logické hře **Quadrax** z let 1994–1996.

## 🎮 O hře
Dva archeologové – Rick a Ben – musí společnými silami překonávat starověké mechanismy, posouvat kamenné kvádry, aktivovat výtahy, propadla a jednosměrné šachty, aby se společně dostali do cílového portálu.

## ✨ Vlastnosti
- **100% Offline:** Běží v jednom souboru bez externích knihoven, CDN i připojení k internetu.
- **Zvukový engine:** Procedurální retro syntéza zvuku přes Web Audio API.
- **12 unikátních úrovní:** Krok za krokem ověřené hádanky včetně integrované nápovědy (klávesa `H`).
- **Nástroje:** Undo historie (krok zpět), výběr úrovní, God Mode a nastavení rozlišení (1x, 2x, 3x).
